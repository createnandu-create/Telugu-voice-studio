## Rebuilding

The Source ZIP includes all application source, Java JNI interfaces, native binaries and compressed phoneme data needed for the documented Gradle build. For changes to native code, unpack the included sherpa source and follow its `build-android-arm64-v8a.sh` / Android build documentation with the Android NDK; enable JNI and TTS/eSpeak. The pinned eSpeak source and its CMake integration are included, as are the build switches in upstream scripts. Follow the pinned ONNX Runtime download/build instructions for that release. These upstream source archives and notices are distributed alongside the APK via the Source ZIP, at no extra cost.

The shipped native binaries are upstream release binaries; this work does **not** claim a bit-for-bit local native rebuild. `scripts/verify-bundle.py` verifies every shipped native/data file. No proprietary voice or cloud engine is included.
